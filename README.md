# Welcome to Pinetree's Website Repository

We are thrilled to welcome everyone to collaborate on our website! To ensure a smooth and organized workflow, please adhere to the following guidelines when contributing:

## Contribution Guidelines

1. **Do Not Modify the "main" Branch Directly**
   - The `main` branch is reserved for stable and approved changes only. Please refrain from making any direct edits to this branch.

2. **Create Your Own Branch**
   - To contribute, create a new branch for your work. Use a descriptive name for your branch that reflects the purpose of your changes (e.g., `feature/add-contact-page` or `bugfix/fix-header-layout`).

3. **Submit Your Changes for Review**
   - Once your work is complete, submit a pull request to merge your branch into `main`. Ensure your changes are thoroughly tested and meet the project standards.

4. **Review and Approval by Rachel**
   - Rachel will review all pull requests and provide feedback if necessary. Once approved, your changes will be merged into the `main` branch.

Thank you for contributing to Pinetree's website! We appreciate your effort and collaboration in making this project a success.
